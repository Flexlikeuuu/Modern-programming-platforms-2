# Лабораторная работа: Многопользовательская веб-игра в режиме реального времени

Многопользовательская игра "Pixel Battle" (битва за территорию на пиксельной сетке 20x20).

## Реализованные требования

1. **Мгновенная синхронизация через WebSockets**:
   - Обновление ячеек игрового поля, рейтинг игроков и журнал событий транслируются всем подключенным клиентам мгновенно.
2. **Только JavaScript, без фреймворков**:
   - Сервер: Node.js (встроенный модуль `http` для статики, библиотека `ws` для WebSocket).
   - Клиент: чистый HTML5, CSS3 и Vanilla JavaScript (DOM API, `WebSocket`). Без React, Vue, Angular и других фреймворков.
3. **Сохранение данных между запусками**:
   - Сервер автоматически сохраняет состояние поля, историю событий и статистику игроков в файл `data/state.json`.
   - При перезапуске сервера данные считываются с диска.
4. **Конкурентный доступ и разрешение конфликтов (8-10)**:
   - Использован механизм оптимистичного управления конкурентным доступом (Optimistic Concurrency Control, OCC) на основе версий ячеек.
   - Каждая ячейка хранит номер версии `version`. При изменении ячейки клиент передает `expectedVersion`. Если версия на сервере уже изменилась (другой игрок занял ячейку раньше), сервер фиксирует конфликт, отклоняет действие, уведомляет игрока и актуализирует состояние.
   - В интерфейсе предусмотрена кнопка "Тест конфликта" для симуляции конкурентного доступа с устаревшей версией.
5. **Работа при потере интернет-соединения (8-10)**:
   - При отключении сети состояние сохраняется в `localStorage`.
   - Действия игрока сохраняются в локальную очередь `offlineQueue`.
   - При восстановлении связи клиент автоматически переподключается и отправляет накопленные действия на сервер с проверкой версий.
6. **Развертывание на хостинге (8-10)**:
   - Конфигурации для хостинга: `render.yaml` и `Dockerfile`.
   - Ссылка на репозиторий: `https://github.com/Flexlikeuuu/Modern-programming-platforms-2/tree/lab4`

## Запуск приложения локально

1. Установка зависимостей:
```bash
npm install
```

2. Запуск сервера:
```bash
npm start
```

3. Открыть в браузере:
```
http://localhost:3000
```
